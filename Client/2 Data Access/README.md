# 2 Data Access - Client (Java)

These workshops cover reading, writing, subscribing and calling methods on OPC UA servers.

| # | Workshop | What you will learn |
|---|----------|---------------------|
| 21 | Read/Write by NodeId | Read and write values using NodeIds |
| 22 | Read/Write by Path | Read and write values using browse paths |
| 23 | Monitoring Items | Subscribe to value changes with monitored items |
| 24 | Simple Method Calls | Call OPC UA methods with input and output arguments |
| 25 | Advanced Calls with Structs | Call methods with nested structures and arrays |
| 26 | Read Attributes | Read node attributes (DataType, Description, AccessLevel, etc.) |
| 27 | Registered Read/Write | High-performance read/write with pre-registered nodes |

**Target server:** `opc.tcp://localhost:48410` (Server Workshop 11 / 13 / 14)
