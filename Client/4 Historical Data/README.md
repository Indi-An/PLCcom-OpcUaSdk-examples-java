# 4 Historical Data - Client (Java)

These workshops cover reading, writing and subscribing to historical data and events.

| # | Workshop | What you will learn |
|---|----------|---------------------|
| 41 | Historical Data | ReadRaw, ReadAtTime (with interpolation), ReadProcessed (aggregates), ReadModified |
| 42 | Historical Data Update | Insert, Update, Replace, Remove, DeleteRaw, DeleteAtTime |
| 43 | Read Historical Events | Read past events from the server history by time range |
| 44 | Monitoring Historical Events | Subscribe to historical event notifications |

**Target servers:** WS41 -> Server 31, WS42 -> Server 32, WS43+44 -> Server 33
